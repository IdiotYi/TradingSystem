# MAW + MACD 中长线趋势回撤策略设计

**日期**：2026-05-03  
**状态**：已批准，待实施

## 1. 目标与范围

新增股票回测策略 `trend_pullback_maw_macd`。它面向以月为持仓单位的中长线交易：只在长期成本趋势向上时参与，在回撤后的恢复阶段以收盘价分批建仓；持仓期间以确定规则加仓、减仓、止盈、止损或清仓。

本次不修改既有三因子、SuperTrend、基金与缠论策略，不接入实盘交易、实时行情、数据库或组合级资金分配。回测继续使用日线、A 股 100 股整数手和现有手续费模型。

## 2. 指标和默认参数

策略只使用以下指标，全部以截至当日收盘的历史数据计算：

| 指标 | 参数 | 作用 |
|---|---:|---|
| MAW | 20、60、120 日 | 月度回撤区、中期趋势、半年长期趋势 |
| MACD | 12、26、9 | 反转确认和高位动能衰减 |
| MAW60 slope | 20 日 | 中期成本趋势方向 |

MAW 沿用 `calc_maw`：成交额/成交量得到 VWAP，按换手率加权，并在存在原始收盘价时换算为前复权口径。数据缺少 `成交额`、`成交量` 或 `换手率`，或任一 MAW 指标在交易区间无有效值时，策略必须返回 `ValueError`，不得静默退化为普通 MA。

MACD 使用 EMA：

$$DIF=EMA_{12}(close)-EMA_{26}(close)$$
$$DEA=EMA_{9}(DIF)$$
$$Histogram=DIF-DEA$$

EMA 以 `adjust=False` 计算；图表显示 `Histogram`，不是双倍柱值。

## 3. 信号、无未来函数和成交模型

每一日按时间顺序执行。先读取第 t 日的 OHLCV 与由 [0,t] 数据计算出的指标，再评估规则，并在 t 日收盘价成交。允许此假设是因为用户可在 15:00–15:30 按收盘价交易。

禁止使用 t+1 或之后的数据、全样本统计量、未来峰谷或回测结果。每条交易记录增加 `signal_date`，且必须等于 `date`；测试必须证明截断未来数据时，截断点以前的指标、目标仓位和交易完全一致。

同一天最多执行一种交易动作，优先级从高到低为：

1. 硬清仓；
2. 趋势清仓；
3. 风险减仓；
4. 高位止盈减仓；
5. 开仓/加仓。

交易采用现有 `_buy_fees` 和 `_sell_fees`，以收盘价、100 股整数手执行。因现金不足导致不能买入时不产生交易。

## 4. 趋势状态和目标仓位

仅当以下三项全部成立时为 `healthy`：

$$Close_t > MAW120_t$$
$$MAW60_t > MAW120_t$$
$$MAW60_t > MAW60_{t-20}$$

无持仓时只有 `healthy` 状态可以开仓；有持仓时趋势失效按第 6 节管理。

`hist_improving` 表示 `Histogram_t > Histogram_{t-1}`；`bullish_cross` 表示 `DIF_t>DEA_t` 且 `DIF_{t-1}<=DEA_{t-1}`。

| 条件（均需 healthy） | 目标仓位 |
|---|---:|
| Close 不高于 MAW60 的 2%，且动能改善或金叉 | 80% |
| Close 低于 MAW20、但高于 MAW60 的 2%，且动能改善或金叉 | 60% |
| Close 不高于 MAW20 的 3%，且动能改善或金叉 | 40% |
| 其他 | 0% |

目标仓位基于当日成交前总资产 `cash + shares * close`。只有目标仓位和当前仓位相差至少 10 个百分点时允许调仓。

## 5. 开仓和加仓

开仓条件：无持仓、目标仓位至少 40%、收盘价不高于 MAW20 的 3%、MACD 满足改善或金叉。首次交易以目标仓位买入，而非固定 50%。

加仓条件：已有持仓、目标仓位比当前实际仓位高至少 10 个百分点，且同时满足：

- 距离最近一次买入至少 5 个交易日；
- Close 低于上次买入价，或当日首次从下方收复 MAW20；
- Histogram 当日不低于前一日；
- Close 高于 MAW120。

每次加仓买入至目标仓位，最大目标仓位严格限制为 80%。

## 6. 减仓、止盈、止损和清仓

所有卖出动作均按当前收盘价，将仓位降至指定上限；若 A 股手数约束导致无法精确达到，则卖出不超过目标上限的最少可交易股数。

### 硬清仓

当平均持仓成本回撤达到 18% 时清仓：

$$\frac{Close_t-average\_cost_t}{average\_cost_t}\le-18\%$$

### 趋势清仓

满足任一项时清仓：MAW60 当日低于 MAW120；或连续 2 个交易日收盘低于 MAW120。

### 风险减仓

若未触发清仓、连续 2 个交易日收盘低于 MAW60，则降至最多 40%。若平均成本亏损至少 12%，也降至最多 30%。同日两者同时满足时采用更低的 30%。

### 高位止盈

若未触发上述规则：

- Close 至少高于 MAW20 的 12%，且 Histogram 连续三日缩短，降至最多 70%；
- Close 至少高于 MAW20 的 20%，且发生 MACD 死叉，降至最多 40%；
- 持仓收益为正、收盘从上方跌破 MAW20，且 MAW20 当日不高于前一日，降至最多 20%。

MACD 死叉定义为 `DIF_t<DEA_t` 且 `DIF_{t-1}>=DEA_{t-1}`。同日触发多条止盈规则时采用最低仓位目标。

## 7. 输出契约和可视化

后端回测响应新增以下等长日序列（无值为 `null`）：`maw60`、`maw120`、`macd_dif`、`macd_dea`、`macd_histogram`、`target_position`、`position_ratio`。

`Trade` 新增 `signal_date`。趋势策略交易原因固定为：`趋势回撤开仓`、`趋势回撤加仓`、`高位动能减仓`、`高位死叉止盈`、`跌破MAW20止盈`、`跌破MAW60减仓`、`成本亏损12%减仓`、`成本亏损18%清仓`、`MAW60跌破MAW120清仓`、`跌破MAW120两日清仓`。

回测摘要新增 `max_position_ratio`、`average_position_ratio`、`rebalance_count`。前端添加“MAW+MACD中长线趋势回撤”；配置区展示只读默认规则与参数；图表主面板显示 MAW20/60/120 和交易标记，副面板显示 MACD、目标仓位与实际仓位。

## 8. 验收标准

1. 新策略缺失 MAW 必需字段时返回 400。
2. API 仅接受已注册股票策略名称，未知策略返回 400。
3. 每笔趋势策略交易的 `signal_date == date`，买卖发生在当天收盘价。
4. 截断未来数据不会改变截断点之前的趋势策略输出。
5. 仓位始终在 0–80%，现金不为负，股份始终为 100 的倍数。
6. 后端完整 pytest 套件通过；前端 TypeScript 和 Vite 生产构建通过。
